## Pontos para revisar

- Limites fundamentais: $\lim_{x \to 0} \frac{\sin x}{x} = 1$ e $\lim_{x \to \infty} \left(1 + \frac{1}{x}\right)^x = e$.
- Regra da Cadeia para funções compostas: $\frac{d}{dx}[f(g(x))] = f'(g(x)) \cdot g'(x)$.
