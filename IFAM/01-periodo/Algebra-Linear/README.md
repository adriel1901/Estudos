## Pontos para revisar

- Propriedades de determinantes: $\det(AB) = \det(A)\det(B)$, e efeito das operações elementares de linha sobre o determinante.
- Condição de invertibilidade: uma matriz $A \in \mathbb{R}^{n \times n}$ é invertível se, e somente se, $\det(A) \neq 0$.
- Definição formal de transformação linear: $T(u + v) = T(u) + T(v)$ e $T(\alpha u) = \alpha T(u)$.
