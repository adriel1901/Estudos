## Modelo Padrão de Revisão para o Subagent IFAM Notes

Ao solicitar uma revisão através do subagent **`ifam-notes`**, o documento gerado deve contemplar:
1. **Tópicos essenciais**: Síntese do escopo;
2. **Conceitos para compreender**: Fundamentos intuitivos e lógica;
3. **Conceitos e fórmulas para memorizar**: Fórmulas essenciais em LaTeX;
4. **Fórmulas e teoremas compilados**: Quadro-resumo;
5. **Exemplos resolvidos**: Resolução detalhada de problemas típicos;
6. **Erros comuns e pegadinhas**: Onde ocorrem as falhas mais frequentes;
7. **Exercícios recomendados**: Questões selecionadas das listas;
8. **Dúvidas pendentes**: Questões a sanar antes do exame.
